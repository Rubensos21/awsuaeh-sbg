# ☁️ AWS Student Builder Group UAEH - ESTL

![AWS Student Builder Group UAEH](./src/assets/svg/logo.svg)

> **Web oficial del grupo estudiantil AWS Student Builder Group en la Universidad Autónoma del Estado de Hidalgo (Escuela Superior de Tlahuelilpan).**

---

El **AWS Student Builder Group UAEH - ESTL** es una plataforma web moderna, interactiva y responsive diseñada para la comunidad universitaria de la **Escuela Superior de Tlahuelilpan (UAEH)** y la región. Su objetivo principal es impulsar el aprendizaje en tecnologías de la nube de **Amazon Web Services (AWS)**, fomentar la colaboración práctica en proyectos de software y facilitar la preparación para certificaciones internacionales.

El sitio combina una **estética visual de alta gama** (diseño en modo oscuro, efectos de resplandor morado y ámbar, tipografía corporativa *Amazon Ember*, animaciones fluidas y retícula pixel-perfect) con una arquitectura cliente moderna basada en **React, TypeScript y Vite**.
