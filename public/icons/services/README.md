# Iconos del catálogo AWS

Los SVG proceden del [paquete oficial de iconos de arquitectura de AWS](https://aws.amazon.com/architecture/icons/), edición del 31 de julio de 2026. Se conserva el contenido original; solo se simplificaron los nombres de archivo.

Archivo de origen: [Icon package, julio de 2026](https://d1.awsstatic.com/onedam/marketing-channels/website/public/shared/architecture-icon-release/Icon-package_07312026.5846e92413caa21490223536cc97f1269e44fa92.zip).

Los iconos y marcas pertenecen a Amazon Web Services. La página de origen describe sus condiciones de uso. El catálogo utiliza un icono de Lucide para la entrada histórica de robótica, cuyo icono ya no está en este paquete.
